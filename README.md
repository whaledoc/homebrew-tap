# WhaleDoc Homebrew Tap

Homebrew formula for the [WhaleDoc CLI](https://github.com/whaledoc/whaledoc-cli), for macOS and Linux.

## Install

```sh
brew install whaledoc/tap/whaledoc
```

## Upgrade

```sh
brew upgrade whaledoc
```

## Uninstall

```sh
brew uninstall whaledoc
brew untap whaledoc/tap
```

Uninstalling keeps your WhaleDoc login and settings. See the [WhaleDoc CLI README](https://github.com/whaledoc/whaledoc-cli#uninstalling) to remove them too.

## How this tap is updated

`Formula/whaledoc.rb` is generated by the [release workflow](https://github.com/whaledoc/whaledoc-cli/blob/main/.github/workflows/release.yml) of the WhaleDoc CLI on every stable release. Don't edit it by hand: changes are overwritten by the next release.
